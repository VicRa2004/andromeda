# Andromeda Storybook

Visual documentation and testing environment for Andromeda UI components using Storybook.

## Getting Started

```bash
npm install
npm run storybook
```

This will start Storybook on `http://localhost:6006`.

## Building

```bash
npm run build-storybook
```

This generates a static Storybook site in the `storybook-static` directory.

## Structure

- `/stories` - Component stories and documentation
- `/.storybook` - Storybook configuration
